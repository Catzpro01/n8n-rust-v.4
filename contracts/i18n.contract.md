# LEGO Contract: Localization (Phase 4B — Backend Native Localization Hub)

**Derived from:** n8n 2.9.4 `reference/n8n/packages/frontend/@n8n/i18n` (`src/index.ts`, `src/types.ts`,
`src/utils.ts`, `src/locales/en.json`, `@n8n/i18n@2.9.2`) and the Phase 4A adapter
(`packages/workflow-lego/src/settings-localization-adapter.ts`).
**Owner:** Agent 1 (workflow / settings-ui line)
**Status:** TESTED — `npm run i18n:check` (5/5 checks) · `node --test test/06-localization.test.mjs` (24/24)
**Phase:** 4B — six locales: `id · en · jv · ar · zh · ru`

> Scope note: upstream n8n ships **English base text only** (`src/locales/en.json`). The six
> translations are product-supplied; this contract therefore pins the *mechanism* and the *key
> parity*, never the wording of an individual translation.

## 1. Interface

```typescript
// packages/workflow-lego/src/backend-localization-service.ts
export type SupportedLocale = 'id' | 'en' | 'jv' | 'ar' | 'zh' | 'ru';
export const FALLBACK_LOCALE: SupportedLocale = 'en';
export const SUPPORTED_LOCALES: Record<SupportedLocale, LocaleMetadata>;
export const NATIVE_DICTIONARIES: Record<SupportedLocale, LocaleMessages>;
export const NATIVE_NUMBER_FORMATS: Record<SupportedLocale, NumberFormats>;
export const BASE_LOCALE_MESSAGES: LocaleMessages;                  // === NATIVE_DICTIONARIES.en
export const BROWSER_STORAGE_KEYS = { locale: 'n8n_locale', updateNoticeSuppressed: 'n8n_update_notice_suppressed' };

export interface LocaleMetadata {
  code: SupportedLocale; name: string; nativeName: string;
  direction: 'ltr' | 'rtl';
  fallbacks: SupportedLocale[];                                     // walked before FALLBACK_LOCALE
  aliases: string[];                                                // normalised input tags
}

export function matchLocale(input: unknown): SupportedLocale | null; // no fallback applied
export function normalizeLocale(input: unknown): SupportedLocale;    // unknown → FALLBACK_LOCALE
export function resolveAcceptLanguage(header?: string | null): SupportedLocale;
export function isRtl(locale?: SupportedLocale | string | null): boolean;
export function isTranslatableKey(key: string): boolean;             // !key.startsWith('_')

export interface TranslateOptions {
  locale?: SupportedLocale | string;
  interpolate?: Record<string, string | number>;
  count?: number;
  defaultValue?: string;
  fallback?: boolean;                                                // false = requested locale only
}
export interface LocalizationPersistencePort { load(): string | null | undefined; save(locale: SupportedLocale): void; }

export class NativeLocalizationService {
  static setLocale(locale: SupportedLocale | string): SupportedLocale;
  static getLocale(): SupportedLocale;
  static getSupportedLocales(): LocaleMetadata[];
  static getLocaleMetadata(locale?): LocaleMetadata;
  static getDirection(locale?): 'ltr' | 'rtl';
  static isRtl(locale?): boolean;
  static isRTL(locale?): boolean;                                     // alias of isRtl
  static formatExecutionMessage(key, params?, locale?): string;        // translate + interpolate
  static attachBrowserStorage(): SupportedLocale;                      // localStorage port + hydrate
  static suppressUpdateBanner(): boolean;
  static translate(key: string, options?: TranslateOptions | SupportedLocale | string): string;
  static t(key: string, options?: TranslateOptions | SupportedLocale | string): string;
  static exists(key: string, locale?): boolean;
  static listKeys(locale?): string[];
  static getMessages(locale?): LocaleMessages;
  static missingKeys(locale?): string[];
  static parityReport(): LocaleParityReport;
  static registerMessages(locale, messages: LocaleMessages): void;
  static resetRegistry(): void;
  static onLocaleChange(listener: (locale, previous) => void): () => void;
  static attachPersistence(port: LocalizationPersistencePort | null): void;
  static hydrate(): SupportedLocale;
  static formatNumber(value: number, format?: string | Intl.NumberFormatOptions, locale?): string;
  static clearCache(): void;
}
```

## 2. Input

| Parameter | Meaning | Source |
|---|---|---|
| `key` | dotted message key (`execute.workflow`) or a nested path (`settings.personal`) | reference `t()` call sites |
| `options.locale` | per-call locale override; BCP-47 tags and legacy codes are normalised | reference `createI18n` locale |
| `options.interpolate` | `{name}` placeholders, inserted verbatim | reference `I18nClass.t(key, { interpolate })` |
| `options.count` | selects the `one | many` form and fills `{count}` | reference `adjustToNumber` call sites |
| `Accept-Language` header | locale negotiation for a request (`resolveAcceptLanguage`) | backend settings payload |
| `LocalizationPersistencePort` | the stored user preference (n8n user settings) | outside the LEGO, injected |

## 3. Output

`translate()` returns a string for every input. A key that resolves nowhere returns
`defaultValue`, else the key itself — exactly like the reference `t()` when a base text key is
missing. `formatNumber()` returns the `Intl.NumberFormat` rendering.

## 4. Semantics (must hold)

1. **English base text is the fallback locale** — `createI18n({ locale: 'en', fallbackLocale: 'en', messages: { en } })`.
2. **Declared chains first**: `jv → id → en`; `ar | zh | ru → en`. Chains are data (`LocaleMetadata.fallbacks`), not code.
3. **Locale normalisation**: case-insensitive, `_` treated as `-`, subtags dropped one at a time
   (`zh-Hans-CN → zh`), legacy codes accepted (`in → id`, `jw → jv`, `zho|chi|cmn → zh`, `arb → ar`),
   anything unmatched → `en`.
4. **Interpolation is verbatim**: values are never HTML-escaped and never sanitised
   (reference `warnHtmlMessage: false`); unknown placeholders stay visible (`{missing}`).
5. **Plural choice**: `count === 1` → first `|`-separated form, otherwise the next form (clamped);
   a message without `|` ignores `count`.
6. **`_`-prefixed keys are plumbing** (`GetBaseTextKey`): excluded from `listKeys()` and from parity.
7. **Key parity is mandatory**: every locale exposes exactly the base text key set (`parityReport().ok`).
8. **RTL is metadata**: `ar` is the only `rtl` locale; direction never changes any translation.
9. **Change notification**: listeners fire once per real change with `(locale, previous)`; re-setting
   the active locale is a no-op and does not write to the persistence port.
10. **Persistence is a port**: the hub never touches a database; `hydrate()` accepts only a supported,
    normalisable value and otherwise keeps the current locale.
11. **Determinism**: `listKeys()` is sorted and duplicate-free; the resolution cache is invalidated on
    `setLocale`, `registerMessages`, `resetRegistry`.

## 6. Errors

The hub is total: it throws for nothing, degrades to the key/`defaultValue`, and never mutates a
caller's objects. `formatNumber` propagates `Intl.NumberFormat` argument errors (invalid options),
which is the reference behaviour for `Intl` misuse.

## 7. Dependencies

- **Imports:** none for `backend-localization-service.ts` (0 imports — the boundary is the point);
  `settings-localization-adapter.ts` imports only the hub.
- **Consumed by:** the settings surface (REST settings payload); the Vue editor bundle consumes the
  payload but is **never modified** (PROJECT_RULES §2).
- **Not owned here:** user-settings persistence (injected port), node translation headers
  (`INodeTranslationHeaders` — node-model LEGO), request routing.
