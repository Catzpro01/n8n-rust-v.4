# P9.20 — Observability Contract Oracle + Cross-Domain Acceptance

Slice: P9.20 · Contract: `observability.contract-oracle@1.0.0` · Owner: agent-6 (product) / Agent 4 (implementation, Issue #101)

## Problem

P3 (workflow/execution), P4 (webhook), P6 (node-registry) and P8 (storage) producers emit contract-shaped specimens into shared pipelines. Drift hides in four ways: a required field disappears, an invented field appears, a vocabulary value mutates, or a version jumps out of the supported range. The oracle is the single deterministic gate that catches all four — with checked-in cross-domain fixtures so every phase keeps a living matrix.

## Contract

| Export | Role |
|---|---|
| `CORACLE_FINDINGS` | `missing_field`, `invented_field`, `vocabulary_drift`, `version_incompatible` |
| `CORACLE_PHASES` | `P3`, `P4`, `P6`, `P8` |
| `CORACLE_LIMITS` | Identifier/field/vocabulary/matrix bounds |
| `createContractOracle` | `{ id, phase, versionRange, fields }` — fail-closed null |
| `validate` | One specimen → frozen report, findings sorted `(code, field, value)` |
| `validateMatrix` | Ordered specimen list → per-report matrix (deterministic) |
| `snapshot` | validated/clean/withFindings + per-code counters |

### Semantics

- **Missing fields** — required schema key absent → `missing_field`; type mismatch also `missing_field` with `value:'type_mismatch'`.
- **Invented fields** — specimen key outside schema (excluding `contractVersion`/`version`) → `invented_field`.
- **Vocabulary drift** — string value outside declared enum → `vocabulary_drift` with `allowed` list.
- **Version incompatibility** — local `satisfies(specimenVersion, versionRange)` with compat public range semantics (R4: `compat.mjs` is not on lego-foundation public surface); missing version → `version_incompatible` with `value:'missing'`.
- **Deterministic output** — per-report sort + frozen structures + `fingerprint` string; fresh oracles over the same matrix deep-equal.
- **Cross-domain fixtures** — `test/fixtures/p9/contract-oracle.json` holds schemas + matrices for all four phases.
- **No I/O, no clock, no workflow/execution/storage import** — sole import `./telemetry-redaction.mjs`.
