# P9.16 — Operator Inspection API

Slice: P9.16 · Contract: `observability.operator-inspection@1.0.0` · Owner: agent-6 (product) / Agent 4 (implementation, Issue #101)

## Problem

Operators need health, readiness, logs, metrics, traces, and diagnostics **as authorized** — with pagination, timeouts, cancellation, and bounded results — without queries blocking workflow runtime or becoming an unbounded scan.

## Contract

| Export | Role |
|---|---|
| `OPERATOR_INTERFACES` | `health`, `readiness`, `logs`, `metrics`, `traces`, `diagnostics` |
| `OPERATOR_ROLES` / `OPERATOR_ROLE_GRANTS` | Explicit access policy (guest denied) |
| `OPERATOR_ERRORS` | Stable machine-readable codes (`operator.unauthorized`, `operator.timeout`, …) |
| `createOperatorApi` | Dataset + optional indexes → `{ query, healthSnapshot, stats }` |
| `query` | Paginated, timeout/cancel aware, index-backed, hard `maxLimit` |
| `healthSnapshot` | Interface list + counters (operator self-status, not workflow health) |

### Semantics

- **Authorized interfaces only** — role must grant the interface; else `operator.unauthorized`.
- **Pagination** — `limit` ≤ 500, `cursor`/`nextCursor`/`hasMore`.
- **Timeouts & cancellation** — `ctl.now` / `ctl.cancelled` produce stable codes; never throw.
- **Bounded results** — max limit, max dataset rows, max in-flight (`operator.busy` under storm).
- **Indexed strategy** — equality uses prebuilt index (`usedIndex: true`); prefix/fallback still row-bounded.
- **Off workflow path** — pure over caller data; no I/O; workflow does not import this module.
- **Stable errors** — `{ ok:false, error:{ code, message, ... } }` always.

## DoD mapping

| DoD requirement | Evidence |
|---|---|
| Six interfaces as authorized | normal query walks all interfaces |
| Pagination | large query multi-page covers dataset once |
| Timeouts / cancellation | `operator.timeout` / `operator.cancelled` tests |
| Bounded results | limit ceiling + page size assertions |
| Access policy | unauthorized guest/unknown/missing role |
| Off workflow path | fail-closed pure queries; no I/O |
| Indexed bounded strategy | `usedIndex` + equality filter counts |
| Stable machine-readable errors | code assertions throughout |

## Required evidence fixtures

1. Normal query — `normalQuery`
2. Large query — multi-page `logs` walk
3. Timeout — `timeoutQuery` + ctl clock
4. Cancellation — `cancelQuery` + ctl cancel hook
5. Unauthorized query — `unauthorizedQuery` (guest)
6. Concurrent query storm — `storm` + `maxInFlight` busy path
