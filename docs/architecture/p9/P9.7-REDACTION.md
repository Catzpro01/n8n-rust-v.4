# P9.7 — Redaction + Data Classification

Status: COMPLETE (stacked on P9.6) · Contract `observability.telemetry-redaction@1.0.0` · Owner agent-6 · Development delegate Agent 4 · Issue #101

## Purpose

One fail-closed boundary every telemetry path routes through **before** persistence or export. Alternate paths (logs, traces, events, export sinks) are not allowed to invent their own redaction rules — they call `redactForExport` / `sanitizeErrorMessage` and receive a frozen envelope.

## Five data classes (deep design §15, least → most restricted)

| Class | Default action | Examples |
|---|---|---|
| `PUBLIC_DIAGNOSTIC` | allow | durationMs, cacheHit, counts, outcome |
| `INTERNAL_DIAGNOSTIC` | allow (bounded) | component, operation, errorCode, bounded strings |
| `SENSITIVE` | redact (`allowPii: true` opts in) | email, phone, IP, fullname |
| `SECRET` | redact always | token/password/credential names; secret-**shaped** values under innocent keys |
| `FORBIDDEN` | reject — value never read | raw request/response bodies, authorization/cookie, credential bags |

`REDACTION_ACTIONS = ['allow', 'redact', 'reject', 'reference']`.

## Boundary rules

1. **Secrets rejected/redacted before persistence & export** — `redactTelemetryTree` walks nested structures with depth ≤ 8, nodes ≤ 512, keys ≤ 64, strings ≤ 512 B; SECRET → `[REDACTED:SECRET]`, FORBIDDEN → `[REDACTED:FORBIDDEN]` without reading the value (FORBIDDEN keys are not traversed).
2. **Error messages sanitized** — `sanitizeErrorMessage` replaces every secret-shaped span (global scan), bounds to 1024 B with `[TRUNCATED]`, returns `null` for non-strings / pathological inputs.
3. **Raw bodies disabled by default** — `body|payload|rawBody|requestBody|responseBody|…` are FORBIDDEN field names; `allowRaw: true` cannot un-forbid them (redaction is not a collection license).
4. **Binary → bounded references** — `Uint8Array`/`ArrayBuffer`/Buffer become `{ binary_ref: true, bytes }`; never base64-inlined.
5. **Accessor safety** — getters are never invoked; FORBIDDEN/SECRET field names still emit markers from the name alone; other accessors are omitted.
6. **Idempotent choke point** — `redactForExport(redactForExport(x))` is a fixed point (markers pass through, `redactionCount` → 0 on the second pass); non-plain roots (functions, dates, numbers) fail closed to `null`.
7. **No I/O, no clock** — pure local functions; source scan forbids `fetch` / `setTimeout` / `fs` / `console`.
