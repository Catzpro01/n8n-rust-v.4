# P9.21 — Advanced Diagnostics / Incident Intelligence

Slice: P9.21 · Contract: `observability.advanced-diagnostics@1.0.0` · Owner: agent-6 (product) / Agent 4 (implementation, Issue #101)

## Scope selection

The P9.21 pool lists 30 candidate advanced features. Per DoD, only features **actually selected** must satisfy containment. Selected (six, each fully contained):

| Feature | Budget | Kill-switch | Fallback | Pressure | AB-safe |
|---|---|---|---|---|---|
| `fast_path` | `fastPathByteBudget` | yes | `slow_path_admit` | over-budget → fallback | yes |
| `delta_telemetry` | `deltaBaselineMax` | yes | `absolute_snapshot` | baseline overflow → typed err | yes |
| `bounded_interning` | `internMaxEntries` | yes | `passthrough_string` | evict oldest (LRU refresh) | yes |
| `burst_dedup` | `dedupMaxEntries` + window | yes | `admit_undeduped` | map cap evict | yes |
| `tail_sampling` | `maxInFlight` | yes | `keep_on_overflow` | in-flight cap → keep | yes |
| `incident_burst_mode` | threshold + cooldown | yes | `steady_mode` | window hard cap | yes |

**Not selected (remain optional / deferred):** profiling, eBPF host adapter, payload offload, materialized views, exemplars, compact histograms, adaptive export batching, cost attribution, policy replay, cross-signal matrix — listed in fixture `notSelected`.

## Hard rules honored

- **Security/audit never deduped by default** — `ADVDIAG_DEDUP_EXEMPT` always admits.
- **Profiling/eBPF optional** — not selected; no code path requires them.
- **Tail sampling bounded** — `maxInFlight` + keep-on-overflow fallback.
- **Workflow A/B** — `workflowAb` is pure `transform(input)`; feature state is metadata only.
- No I/O, no clock (`now` is an argument), sole import `./telemetry-redaction.mjs`.
