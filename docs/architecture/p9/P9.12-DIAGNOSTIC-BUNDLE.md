# P9.12 — Diagnostic Bundle Compiler

Status: IN PROGRESS (stacked on P9.11) · Contract `observability.diagnostic-bundle@1.0.0` · Owner agent-6 · Development delegate Agent 4 · Issue #101

## Purpose

Compile a **bounded, deterministic diagnostic bundle** from correlation context + selected signals (logs/events/spans): size **and** time budgets enforced, **secret** redaction mandatory, missing evidence explicit (`evidenceMissing`), export/import integrity verifiable (`BDL:v1:` digest), repeated generation byte-identical for the same inputs+policy. Refs, not payloads: large state stays a reference (deep-design §18/§28). No I/O, no clock, no workflow import.

## Schema (`schemaVersion` 1.0.0)

| Block | Contents |
|---|---|
| `schemaVersion`, `contractVersion` | `1.0.0` / contract version |
| `correlation` | required `executionId` + `workflowId`; optional allowlist (`DIAG_BUNDLE_CORRELATION_FIELDS`) |
| `policy` | `maxBundleBytes`, `maxTimeWindowMs`, `maxLogs`, `maxEvents`, `maxSpans`, `minSeverity` |
| `diagnostic`, `resource`, `refs`, `configFingerprints` | optional evidence blocks; absent → listed in `evidenceMissing` |
| `logs`, `events`, `spans` | selected signals only (never full dumps) |
| `evidenceMissing` | explicit bounded list of absent fields/blocks (priority: sections + core, then correlation ids) |
| `dropped` | per-kind counts + reasons (`window`, `relevance`, `budget`, `invalid`) |
| `budget` | `{ maxBytes, usedBytes, exceeded }` |
| `integrity` | `{ alg: 'fnv1a-pair-v1', digest: 'BDL:v1:<16hex>' }` |

## Budgets

- **Size:** greedy fill under `policy.maxBundleBytes` (default 32768, floor 512, absolute ceiling `maxWireBytes` 65536). Skeleton bytes counted first; candidates that would overflow are dropped with reason `budget`. `budget.exceeded` is honest (`usedBytes` vs `maxBytes`).
- **Time:** candidates outside `[anchor − maxTimeWindowMs, anchor + maxTimeWindowMs]` are dropped (`reason: window`); default window 900000 ms.
- **Counts:** per-kind caps (`maxLogs` 64, `maxEvents` 64, `maxSpans` 32); candidates above cap never enter the bundle.
- **Relevance:** `minSeverity` filter (default INFO) for logs/events; score = severity + error/outcome weight, then timestamp, then original index (deterministic order).

## Selection (no full dumps)

`compileDiagnosticBundle(spec)` takes **candidates** (logs/events/spans arrays), normalizes each through the P9.7 secret boundary, filters by window/severity, sorts deterministically, and greedily fills under count + byte budgets. Anything not selected is counted in `dropped` (never silently lost). Only the selected subset appears in the bundle.

## Secret redaction (mandatory)

- Structural candidate fields with secret shapes → candidate rejected (`invalid`), never embedded.
- Free-text `message` with secret shape → replaced with `REDACTION_MARKERS.secretValue` (`[REDACTED:SECRET]`).
- Correlation ids / refs / config fingerprint values pass `containsSecretShape` + `classifyTelemetryField` (fail-closed on secret).
- Export re-scans the full body; secret-shaped export → `null`.

## Evidence missing (explicit)

Absent optional correlation fields and absent evidence blocks (`diagnostic`, `resource`, `refs`, `configFingerprints`, `logs`, `events`, `spans`) are listed in `evidenceMissing`. The list is bounded (`maxMissing` 32); truncation prioritizes signal sections and core blocks so a correlation-only bundle still reports `logs`/`events`/`spans` as missing. Bundle remains usable (export/import round-trip works).

## Integrity (`BDL:v1`)

- Digest = `BDL:v1:` + fnv1a-pair over `stableStringify(bodyWithoutIntegrity)` (pure, no clock).
- `exportDiagnosticBundle(bundle)` recomputes and embeds `integrity`.
- `importDiagnosticBundle(wire)` fails closed on: non-JSON, missing/mismatched digest (tamper), secret shapes, non-plain structure, wrong schema/contract version.
- `verifyBundleIntegrity(bundle)` recomputes and compares.
- Repeated generation for same inputs+policy → byte-identical wire (stability test).
