# P9.11 — Execution Diagnostics Contract

Status: COMPLETE (stacked on P9.10) · Contract `observability.execution-diagnostics@1.0.0` · Owner agent-6 · Development delegate Agent 4 · Issue #101

## Purpose

Bounded, secret-safe diagnostics for a (failed or successful) execution: correlate to workflow/version/trigger/node/runtime; attach resource state and checkpoint/replay/artifact **references**; represent missing evidence explicitly; emit a standardized failure summary with a stable `FFP:v1:` fingerprint. Large execution state is **referenced, never duplicated**. P9 correlates references — it does not own execution persistence or the replay engine (deep design §26).

## Identity correlation

Allowlisted fields (`EXEC_DIAG_IDENTITY_FIELDS`): `executionId`, `workflowId` (**required**), `workflowVersion`, `triggerId`, `nodeId`, `nodeType`, `nodeVersion`, `runtimeId`. Missing optional ids → `null` + entry in `evidenceMissing`. Missing required ids or secret-shaped values → **fail closed (`null`)**.

## Evidence attachments

| Kind | Field | Bound |
|---|---|---|
| resource | `resource` (numeric/short-string values) | ≤ 16 fields; sensitive keys dropped via P9.7 classification |
| checkpoint / replay / artifact | `refs` | ≤ 16 ids; `safeRef` rejects secret/Bearer shapes |
| large state | `state` | inline only ≤ 4096 B; larger → `{ state_ref, ref, bytes }` (value not copied) |
| nodes | `nodes[]` | ≤ 32 bounded identities |

## Failure summary + fingerprint

`summarizeFailure(diag)` (failed only) → frozen summary with `FFP:v1:<fnv1a>` over fixed-order non-secret identity/failure fields. Same inputs → same fingerprint; changed code → different. Summary ≤ 1024 B, secret-safe.

## Secret-safe

- Identifiers/values pass `containsSecretShape` + P9.7 `classifyTelemetryField` (reject/redact).
- Failure `message` with secret shape → replaced with `[REDACTED:SECRET]` (never stored raw).
- `serializeExecutionDiagnostic` is the export choke (wire ≤ 8192 B, rejects secret shapes).

## Missing evidence

Optional blocks absent → listed in `evidenceMissing` (identity nulls for optional fields). Diagnostic remains valid and summarizable (usable when evidence is missing).
