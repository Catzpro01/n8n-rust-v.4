# P9.13 — Failure Correlation + Causal Evidence

Status: IN PROGRESS (stacked on P9.12) · Contract `observability.failure-correlation@1.0.0` · Owner agent-6 · Development delegate Agent 4 · Issue #101

## Purpose

Compile a **bounded failure-correlation graph** from failure events + edges: four cause kinds (`OBSERVED_CAUSE` / `INFERRED_CAUSE` / `CORRELATED_WITH` / `UNKNOWN`), **evidence refs** attached where causality is claimed, **confidence + source** mandatory on inference, correlation **never** promoted to certainty, unknown roots reported honestly, cycles terminate without infinite expansion. No I/O, no clock, no workflow import.

## Schema (`schemaVersion` 1.0.0)

| Block | Contents |
|---|---|
| `schemaVersion`, `contract` | `1.0.0` / `observability.failure-correlation@1.0.0` |
| `events` | `{ id, kind, evidence? }` — bounded (`maxEvents` 128) |
| `edges` | `{ from, to, kind, evidence?, confidence?, source? }` — bounded (`maxEdges` 256) |
| `rootId` | failure under investigation; must reference an event |
| `evidenceMissing` | explicit list (`eventEvidence`, `causalEdges`) when absent |
| inbound/outbound adjacency | built in compile (not serialized on export) |

## Cause kinds

| Kind | Required | Semantics |
|---|---|---|
| `OBSERVED_CAUSE` | `evidence[]` non-empty | direct causal claim backed by evidence |
| `INFERRED_CAUSE` | `confidence` in [0,1] + `source` | probabilistic inference; never presented as observed |
| `CORRELATED_WITH` | `evidence[]` non-empty | association only — **never promoted** to cause |
| `UNKNOWN` | — | classification result when no causal inbound claim exists |

## Classification (`classifyRootCause`)

1. Inbound `OBSERVED_CAUSE` exists → `rootKind: OBSERVED_CAUSE`.
2. Else inbound `INFERRED_CAUSE` → `rootKind: INFERRED_CAUSE` + highest `confidence`/`source` + note `inferred-not-observed`.
3. Else inbound `CORRELATED_WITH` only → `rootKind: UNKNOWN` + note `correlation-only-not-promoted`.
4. Else → `rootKind: UNKNOWN` + note `no-inbound-causal-claims` (and `causalEdges` in `evidenceMissing` when edges empty).

## Expansion (`expandCausalChain`)

- BFS over inbound edges from root; **each node visited at most once**.
- Re-encountering a visited ancestor → `cycleDetected: true` (still terminates).
- Hard caps: `maxExpansionDepth` 64, `maxPathNodes` 64; result always `terminates: true`.
- `pathLength` = path nodes − 1 (root excluded from length count as start).

## Evidence (`attachEvidence`)

Merges additional evidence refs into existing edges by key `from+to+kind`. Unsafe refs (secret-shaped / bearer tokens) → `null`. Observed/correlated edges cannot end with empty evidence.

## Export (`exportFailureCorrelation`)

Canonical stable JSON of body (schemaVersion, contract, events, edges, rootId, evidenceMissing). Adjacency maps excluded. Secret-shaped content → `null`. Same graph → same bytes.
