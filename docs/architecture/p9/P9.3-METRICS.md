Unit `1` values must be nonnegative safe integers; ratios and milliseconds are
finite nonnegative numbers <= MAX_SAFE_INTEGER. Gauges retain the last supplied
observation, not a running sum or synthetic current provider value. Unobserved
series are **not emitted** (unknown is not zero). Caller must timestamp/scope the
snapshot at its own boundary. Resource collection remains P9.9.

## Distribution contract

Disjoint buckets with inclusive upper bounds, milliseconds:
`1,5,10,25,50,100,250,500,1000,5000`, followed by one overflow bucket `(5000,+inf)`.
Bucket counts sum to count. No raw sample history. Sum is IEEE-754 floating point
(with its usual precision limits); exceeding MAX_SAFE_INTEGER rejects the sample
atomically. Counters use safe integer arithmetic and reject overflow. Individual
quantiles cannot be reconstructed exactly: adapters may report approximate
bucket bounds, never invent exact p95/p99. Exporters may translate to cumulative
buckets at their boundary; the native contract stays disjoint/backend-neutral.

## Cardinality Governor

`createMetricGovernor({maxSeries})` requires an explicit global slot budget,
**38..4096**, including one reserved aggregate slot per family. Invalid config
returns null; no unlimited default. Instance methods: `observe`, `snapshot`,
`stats`, `reset`. `observe(name,value=1,labels={})` returns boolean, never a
business exception. Name/schema unknown => false; telemetry rejection only.

Allowed dimensions: `component`, `severity`, `outcome`; their finite value sets
are published in `METRIC_LABEL_POLICY`. Severity reuses P9.1. No label registry
learns attacker-supplied strings. Unknown allowed-label values bucket to **other**.
Business/workflow/execution/node/request/tenant IDs, URLs, secrets and all other
label names are discarded **without reading their values**. Keep those IDs in
P9.1 correlation context outside metrics, not metric labels or a hash dictionary.
Input metadata is bounded to 8 own labels, key/value strings <=64 characters.
Symbols, getters on allowed labels, nested values and malformed inputs reject.

When a new normalized dimension combination would exceed maxSeries, its value
is aggregated into the family's reserved unlabeled slot. Other families cannot
be starved by one producer exhausting the global budget. Existing series remain
updatable. Dimension loss is visible through `reducedCount` per series,
`cardinalityRejected` (discarded/bucketed dimensions) and `aggregated` (samples
redirected because slots are exhausted). The counters themselves are bounded and
saturate at MAX_SAFE_INTEGER; they never recursively emit telemetry.

A dimension-reduced gauge is explicitly the **last observation across reduced
scopes**, not a sum, per-node gauge, or tenant-specific value. Consumers must
inspect reducedCount before interpreting scope. This is the documented fidelity
trade-off for bounded state. No raw identifier value survives in retained state.

## Lifecycle/resource/security

No network, disk, timers, clock reads, JSON encoding, payload cloning or execution
imports on observation. Small temporary label validation objects are allocated;
this is **not zero allocation**. Retained state consists only of bounded maps,
finite-enum keys, scalar accumulators and 11 histogram counters per histogram
series. Memory cannot grow with samples/rate or unique IDs after the slot budget.
No absolute JS RSS ceiling is claimed; the bound is structural retained state.

Snapshot is a bounded, detached immutable view, ordered by published family order
and normalized label key. Keep query snapshots outside the workflow hot path.
Callers own any copies they retain. Reset starts a new caller-owned aggregation
window and releases dimensions; no automatic clock/retention scheduler is added.
No persistence, exporter, provider, query endpoint, metric-to-runtime feedback,
or multi-tenant infrastructure. Default global labels never carry tenant IDs.
Local inputs are trusted bounded metadata, not a hostile-JS isolation boundary.
