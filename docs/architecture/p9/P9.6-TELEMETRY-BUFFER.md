# P9.6 — bounded telemetry buffer and backpressure

Authority #101 P9.6; product owner Agent 6, implementation delegate Agent 4.
Stacked on P9.5 (`0b8bd9e2`); baseline `24032a0c`. No P3/P4/P6/P8 import, no
disk spill in 1.0.0, no clock/I/O/callback on offer/take/stats.

## Contract

`observability.telemetry-buffer@1.0.0`, module
`apps/n8n-lego/src/telemetry-buffer.mjs` → `src/lego/telemetry-buffer.mjs`.

| Export | Meaning |
| --- | --- |
| `TELEMETRY_PRIORITY_CLASSES` | `P0..P4` (deep design §12): security/audit, failure, lifecycle, performance, debug |
| `BUFFER_OUTCOMES` | `buffered \| shed \| rejected` — every offer answers explicitly |
| `BUFFER_OVERFLOW_POLICIES` | `shed_lowest` (default) \| `reject_incoming` |
| `BUFFER_LIMITS` | capacity 1..65536; take ≤ 65536 |
| `createTelemetryBuffer(config)` | null on invalid config — **capacity is required** |

## Rules proven by tests

1. **Hard maximum**: preallocated ring of exactly `capacity` slots; `size ≤
   capacity` by construction (saturation + 50-cycle overload tests).
2. **Deterministic overflow**: `shed_lowest` evicts at most one resident and
   only a **strictly** lower priority (equal never evicts equal); when nothing
   strictly lower remains → incoming sheds. `reject_incoming` never evicts.
3. **Priority classes**: P0 security/audit → P4 debug; low-priority sheds
   before critical evidence (fill with P3/P4, admit P0 by evicting P4 only).
4. **Drop counters**: `stats()` exposes `buffered/shed/rejected/evicted`,
   per-class `shedP0..shedP4`, `peakSize`, `occupancy`, `droppedTotal` —
   no silent loss.
5. **No unbounded path**: capacity required; invalid config → `null`; source
   scan forbids timers/fs/fetch; only `new Array(capacity)` allocation wall.
6. **Workflow A/B under saturation**: business function returns identical
   results with no buffer / healthy buffer / 10k-offer saturated buffer;
   `offer` never throws (malformed → `rejected`).
7. **Spill-to-disk**: not implemented in 1.0.0 (DoD: "if implemented" — a
   future additive quota-bounded spill gets its own version decision).

## Non-goals

Exporter, retention tiers (P9.15), sampling (P9.8), operator API (P9.16).
Payloads are opaque references already bounded by their producer contract;
the buffer never clones or serializes them.
