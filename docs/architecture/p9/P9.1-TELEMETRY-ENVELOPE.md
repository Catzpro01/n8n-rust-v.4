## Contract and schema

`observability.envelope@1.0.0`, public module
`apps/n8n-lego/src/lego/telemetry-envelope.mjs`.
Structural JSON schema: [telemetry-envelope.schema.json](telemetry-envelope.schema.json).
Canonical full fixture: `apps/n8n-lego/test/fixtures/p9/envelope.json`.

| Field | Meaning and restriction |
| --- | --- |
| contractVersion | Exactly `1.0.0` on the wire; supplied by constructor |
| timestamp | Required nonnegative JS-safe integer, Unix epoch milliseconds; producer supplies it |
| signalType | Required `LOG / METRIC / TRACE / EVENT / RESOURCE / DIAGNOSTIC` |
| component | Required non-secret component identifier |
| severity | Optional `TRACE / DEBUG / INFO / WARN / ERROR / FATAL`, from #101; no P9.2 log implementation yet |
| environment, operation, outcome | Optional bounded machine identifiers; no message text |
| errorCode, errorClass | Optional producer-owned machine identifiers, not exception message/stack; preserve existing error vocabulary |
| artifactRef, diagnosticRef | Optional opaque references, never URLs or inline artifacts |
| context | Required immutable, reusable correlation context; may be empty |

Context optional fields in canonical order: `workflowId`, `workflowVersion`,
`executionId`, `nodeId`, `nodeType`, `nodeVersion`, `triggerId`, `requestId`,
`correlationId`, `causationId`, `traceId`, `spanId`, `parentSpanId`, `checkpointId`,
`runtimeId`, `registryEpoch`, `runtimeLeaseId`, `resourceBudgetId`, `tenantId`.
`registryEpoch` is a nonnegative JS-safe integer. All other values are opaque
non-secret strings of 1–128 ASCII bytes, `[A-Za-z0-9][A-Za-z0-9_.:/-]*`.
No missing ID is generated or guessed. Trace IDs remain opaque here: P9.4 owns
trace validation/propagation semantics. Epochs above JS safe range need a new
contract, not silent precision loss.

## API, lifecycle and compatibility

1. At a trusted producer boundary, `createTelemetryContext(spec, policy?)`
   validates and freezes a context once. Invalid metadata returns `null`.
2. `deriveTelemetryContext(parent, changes, policy?)` preserves unchanged IDs.
   `telemetryContextFromEnvelope(existingEnvelope)` copies only the foundation's
   existing request/correlation/causation/trace identity. It does **not** copy
   actor, scope, idempotency keys or cancellation objects.
3. The successful-operation path calls `createTelemetryRecord(spec, context)`.
   It shares the frozen context by reference. It performs no payload traversal,
   JSON encoding, clock read, remote call, disk access, callback or stack capture.
4. Optional slow-boundary `serializeTelemetryRecord` / `deserializeTelemetryRecord`
   uses deterministic field order. Codec limit: **8192 ASCII bytes**. Producer
   field-count and 128-byte scalar limits bound every legal full record below
   that limit; a maximum-occupancy fixture verifies this.
5. Each API returns a value or `null`; never an input-bearing exception.
   Null means rejected telemetry, not failed workflow. P9.1 does not buffer,
   persist, call a sink or retain records. WeakSets brand objects without strong
   retention, and records follow caller lifetime/GC.

The decoder accepts **only the canonical encoding emitted by the codec**:
no whitespace variants, duplicate keys, reordered fields or unknown fields.
Only exact version `1.0.0` is supported; malformed/newer/older versions are
unsupported (`null`), never silently interpreted. There is no migration in this
initial release. Future compatibility requires an explicitly versioned adapter;
OTLP objects are not the internal contract. This codec is not a generic JSON API.

## Security and tenant authorization

- No payload/attribute bag, message, stack, credential, header, body or arbitrary
  nested object is supported. Unknown fields (including secret-bearing fields)
  reject the entire record, not merely disappear after capture.
- URLs, whitespace/control characters and recognizable token formats are denied
  even in allowed identifier fields. Returned rejections contain no supplied data.
- These checks **cannot identify every arbitrary secret disguised as an opaque
  ID**. Trusted producers must project only their authoritative non-secret IDs;
  never put names, user-entered text, credentials or request bodies in these slots.
- Accessors, symbols, non-enumerable fields and custom prototypes are rejected.
  Throwing proxies are caught. This is not a sandbox for malicious JS proxies
  with infinite-loop traps; such code requires the owning runtime isolation.
  Local input objects must already be bounded metadata, not attacker-sized maps.
  Serialized boundary input is capped before parsing.
- Tenant capture defaults to denied. An existing authorized boundary supplies
  `policy.authorizedTenantId`; the value must exactly match. Derivation and
  decoding reauthorize. That policy is trusted application input, **not** an
  authorization engine and not data copied from the request. Queries/export
  scoping are P9.16/P9.19, not implemented here.

- P4 (#99): request/correlation/trigger references; no admission or scheduling.

  producer-owned; P9.2 will classify logs without reinterpreting business errors.

## Resource profile and degradation

No SDK or new dependency. No persistent storage, queue, worker, exporter or timer.
A new JS record and short validation temporaries are allocated per admitted event;
**not zero allocation**. Shared contexts avoid repeated context copies. Full
metadata validation is cold-boundary work. Creation has bounded field/value work
for trusted bounded metadata; no claim of hard real-time isolation.

Invalid metadata/unsupported codec input => `null`, producer continues its own
business operation. Integration must not treat `null` as a workflow exception.
Safety-required evidence must be enforced by its explicit owning policy, not an
implicit envelope-construction dependency. Remaining non-interference modes and
end-to-end runtime evidence belong to later milestones/P9.22.
