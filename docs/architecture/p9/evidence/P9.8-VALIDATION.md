## Bugfixes during slice (do not regress)

1. **Hash unsigned** — final avalanche `h ^= h >>> 16` left signed int32; `hashUnit` returned negatives → every decision kept. Fixed with `>>> 0` after every `^=`.
2. **Adaptive cooldown** — errors at maxRate kept incrementing the cooldown counter so the first healthy decision decayed immediately. Fixed: any error resets `decisionsSinceChange = 0`.
3. **Baseline validation scope** — `rate: 0` on HEAD failed because default `baselineRate = rate` was checked against `minRate: 0.01` for all modes. Adaptive baseline check now applies only when mode is ADAPTIVE (or when `baselineRate` is explicitly provided).

## Classification decisions (not bugs)

- `RATE_LIMITED` not in `SAMPLING_MODES` — explicitly scoped out of 1.0.0 per DoD (“implemented or explicitly scoped”).
- Non-tail `begin`/`end` on OFF/HEAD/… are accepted no-ops (release-only) so callers can share one tail-shaped API.
