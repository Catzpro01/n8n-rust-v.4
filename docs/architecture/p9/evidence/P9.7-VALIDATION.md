## Bugfixes during slice (do not regress)

1. **Global replace** — `SECRET_VALUE` is non-global (`i` only) so `.test()` has no `lastIndex` drift; sanitize builds a fresh `gi` copy per call so every secret span is replaced (first-pass only bug left `Authorization: Bearer …` in logs).
2. **Idempotent markers** — already-redacted marker strings pass through without re-counting (export twice → `redactionCount: 0`).
3. **Accessor markers** — getters never invoked; FORBIDDEN/SECRET names still emit markers from the name; other accessors omitted.
4. **allowPii** — SENSITIVE-class redaction is policy-controlled; SECRET/FORBIDDEN never loosen.

## Classification decisions (not bugs)

- Field `auth` / `authorization` / `cookie` are **FORBIDDEN** names (not SECRET) — collection is the violation.
- `apiKey` is exact FORBIDDEN key; `x-api-key` matches SECRET via `api[-_]key`.
