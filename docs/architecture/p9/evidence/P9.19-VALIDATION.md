## Fixes during slice (do not regress)

1. **Global auth ≠ raw row dump** — even `scope:'global'` on `query()` fails closed; only `globalAggregate` returns cross-tenant data and only as counts.
2. **Single mode forbids tenantId** on ingest, query filter and route — keeps the path light and prevents accidental multi-tenant behavior.
3. **Cross filter returns no report** — fail-closed before any row materialization.
4. **Contract-lock 71→72** — clean append; count-pins 71→72.
5. **Arch/F16** — sole import `telemetry-redaction`; no bare unpublished namespace strings.
6. **Label denylist** = fixed keys ∪ `/tenant/i` — both deny paths tested.

## Classification decisions (not bugs)

- `global_unauthorized` is a security counter, not an error regression.
- Single-tenant `globalAggregate.tenantCount === 0` by design (no tenant dimension exists).
- `records_shed` on cap is honest backpressure, not leakage.
