## Fixes during slice (do not regress)

1. **Candidates loop kind/section mismatch** — `candAllowed` iterated plural section names (`logs`) but `normalizeCandidate` expected singular kinds (`log`); `normalized['logs']` was undefined → compile returned `null`. Fixed with `kindOf` map.
2. **Fixture `expect` key** — fixtures carry a non-contract `expect` annotation; `compileInput` strips it before compile (SPEC_KEYS fail-closed on unknown keys).
3. **Secret-shaped log `message` rejected whole candidate** — structural fields still fail closed; free-text `message` is redacted to marker instead of dropping the log.
4. **`evidenceMissing` truncation** — `maxMissing` raised to 32; truncation prioritizes signal sections + core blocks so `logs`/`events`/`spans` remain listed.

- `policy.maxBundleBytes` below floor (512) or unknown policy keys → `null` (fail-closed).
- Unknown spec keys (`extra`) → `null`.
