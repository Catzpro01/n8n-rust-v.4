## Contract and APIs

`observability.trace@1.0.0`, native span `{contractVersion,context,sampled}`.
Structural schema: [trace-context.schema.json](trace-context.schema.json).
`context` is the immutable, branded P9.1 context (not an SDK object). Existing
workflow/version/execution/correlation/tenant identity is never silently reassigned.

- `createTraceSpan(spec, baseContext, policy?)`: spec has traceId (32 lowercase
  nonzero hex), spanId (16 lowercase nonzero hex), optional parentSpanId (16 hex,
  nonzero and different from spanId), sampled (boolean; default false).
- If the base already belongs to a trace, the traceId must match. If it already
  has a spanId, that ID must be the new parentSpanId; silently orphaning it fails.
- `createChildTraceSpan(parent, newSpanId, changes?, policy?)` inherits trace,
  sampled flag, workflow/version/execution/correlation and tenant identity.
  Only child-local request/causation/node/trigger/runtime/checkpoint/lease/epoch/
  budget references may change through the existing context validator.
- `injectTraceParent(span)` emits a 55-byte W3C traceparent **v00** carrier.
- `parseTraceParent(header)` admits only exact v00, lowercase nonzero IDs, flags
  00/01. Unknown versions/flags, extra fields/whitespace or CRLF return null.
- `continueTrace(header, localSpanId, trustedBaseContext, policy?)` makes a new
  local child whose parent is the REMOTE span in the header. The header never
  supplies workflow/execution/tenant authorization.
- `createTracePayloadReference({sha256,sizeBytes})` accepts only 64 lowercase
  hex digest characters and a nonnegative safe integer size. This is reported
  metadata, not proof that a hash was computed correctly and not read authority.

All malformed construction/carrier inputs return null without input-bearing
errors. Unknown native properties/versions are rejected, and forged/cloned span
objects cannot be injected as trusted local spans. P9.1 wire codec separately
carries correlation across worker/process boundaries. This module neither opens
connections nor changes how upstream runtimes communicate.

## Identity, scope and compatibility

Caller supplies unique IDs (typically from its established tracing/ID boundary).
No entropy source or unbounded global uniqueness/ancestry registry is introduced.
The module validates immediate parent linkage, not global historical uniqueness
or a complete distributed trace DAG. The producer remains responsible for fresh
span IDs, including avoiding reuse of a more distant ancestor ID. Trace links
are correlation evidence, not proof of business causality (P9.13 owns that).

Only the documented W3C subset is supported; tracestate, baggage, future wire
versions and additional flag bits are not silently interpreted. Existing opaque
P9.1 legacy trace IDs remain valid P9.1 data but are not automatically upgraded
into this stricter trace format. Applications need an explicit adapter.

Tenant capture/derivation still requires exact existing P9.1 authorization.
A header cannot grant tenant access. sampled=false keeps identical correlation
IDs; the flag is metadata only, not a sampler/admission/runtime decision.

## Payload and secret safety

No payload, header bag, message, stack, credentials or attributes can enter the
span API. Unknown fields reject before value traversal. Only hash+size references
are created; existing P9.1 artifactRef/diagnosticRef remain available on separate
telemetry records. No hashing, payload copying or enrichment occurs here.
Upstream policy must not hash/capture credentials merely because a hash slot
exists. Hashes can still be sensitive; this API grants no permission to expose them.

The 4 MiB test computes a real digest outside the producer, then verifies only a
<128-character metadata object is returned. Unknown payload getters never run.
Malformed sizes/digests reject. Local inputs are trusted bounded metadata, not an
isolation sandbox for malicious JS proxies/monkey-patched intrinsics.

## Lifecycle, resource and degradation

Native objects are frozen and weakly branded; no span history/store/queue is
retained. Contexts share immutable strings, not business execution payloads.
Child construction allocates bounded metadata copies; not allocation-free.
No clock, serializer, random generator, I/O, exporter or SDK dependency on the
producer path. Carrier injection is string assembly only, at a real boundary.
Caller controls lifetime and optional emission. Invalid/unavailable trace data
returns null: workflows are not failed, and no caller code is wrapped/replaced.
