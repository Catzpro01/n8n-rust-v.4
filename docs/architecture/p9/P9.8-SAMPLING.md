# P9.8 — Sampling + Adaptive Telemetry Policy

Status: COMPLETE (stacked on P9.7) · Contract `observability.telemetry-sampling@1.0.0` · Owner agent-6 · Development delegate Agent 4 · Issue #101

## Purpose

Policy-controlled reduction of telemetry volume **before** it reaches the bounded buffer/export path. Sampling only ever reduces retained signals — it never increases workflow memory (tail state is a preallocated array with a hard `maxInFlight` ceiling).

## Modes (DoD vocabulary)

| Mode | Behavior |
|---|---|
| `OFF` | Sampling disabled — every signal kept (`mode_off`). |
| `HEAD` | Deterministic early reduction via seeded FNV-1a hash (`head_hash`). |
| `TAIL` | `begin`/`end`: keep errors (`tail_error`) and slow traces (`tail_latency`); head-sample completed successful traces (`tail_summary`); overload → head fallback (`tail_overload_fallback`). |
| `ERROR_PRIORITY` | Keep all errors; head-sample successes. |
| `LATENCY_PRIORITY` | Keep signals with `durationMs >= slowMs`; head-sample the rest. |
| `ADAPTIVE` | Bounded rate controller: raise on error, decay toward baseline after cooldown; hard `minRate`/`maxRate` clamps. |

**`RATE_LIMITED` is explicitly scoped out of 1.0.0** (DoD allows implemented *or* scoped modes).

## Controller rules

1. **Deterministic** — same `seed` + policy + key → identical keep/drop sequence (no `Math.random`, no clock).
2. **Min/max bounds** — adaptive rate never leaves `[minRate, maxRate]`; baseline must sit inside for ADAPTIVE.
3. **Hysteresis/cooldown** — any error restarts the cooldown counter; healthy decay only fires after `cooldownDecisions` consecutive healthy decisions (prevents oscillation).
4. **Overload fallback** — when tail in-flight is full, `begin` decides immediately via head hash and does **not** store a slot (memory never grows past `maxInFlight`).
5. **Tail hard bound** — in-flight slots are a preallocated `Array(maxInFlight)`; `stats().inFlight` / `peakInFlight` are the budget accounting.
6. **Fail closed** — invalid config → `null`; hostile signals never throw; decisions always in `{keep, drop}`.
7. **No I/O, no clock** — pure local functions (source scan forbids `fetch`/`setTimeout`/`fs`/`console`/`Date.now`/`Math.random`).
