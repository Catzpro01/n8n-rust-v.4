## Defects fixed

1. `cleanup.yml` checked out `main` with `fetch-depth: 1`. When another PR merged in the meantime, the runner could
   not find the merge commit and aborted. Now:
   - full-history checkout;
   - the runner proves that the merge commit exists and is an ancestor of `origin/main`;
   - it deepens, fetches the SHA explicitly and, as a last resort, unshallows before giving up;
   - nothing is deleted before that proof.
2. The only protected names were `main` / `master`, and the delete ran inside the Supabase block. Now `main`,
   `master` and `arena-manager` are never deleted, whatever the PR head was: PROTECTED, a warning annotation,
   exit 0.
3. A head branch that is already gone (including a lost race with GitHub auto-delete) exits 0 with a clear message.
4. The legacy Supabase control plane is best-effort and never blocks the cleanup. Subprocess output is redacted.
