## 3. Contract guarantees (what a reviewer can check without running code)

| Guarantee | How it is declared |
| --- | --- |
| Versioned contract | `memory.json#version: "1.0.0"` locked in `contract-lock.json` |
| Operation set minimal | `memory.remember`, `memory.recall`, `memory.list`, `memory.forget` only (`openDecisions` documents why `delete/forget` is justified: GDPR / sensitive-data, idempotent and unrecoverable) |
| Permissions | `ai:memory:read` (`recall`, `list`), `ai:memory:write` (`remember`, `update`, `forget`) |
| Lifecycle | `active → archived → forgotten` (archived is `forget` via `retention: archived` alias; `forgotten` is terminal) |
| Record vs reference | `record` is full bounded memory; `reference` is `graphRef: {entityKind, entityId, kind, scope, checksum}` — Context references Memory, never owns |
| Integrity | `sha256Hex(canonicalJson({scope,kind,content,retention}))` stored as `checksum`, verified on `recall`/`list`/`verify` |
| Scope isolation | `scope` is required on `remember` and on `recall`/`list`; missing scope fails `ERR_SCOPE_REQUIRED`; cross-scope reads never leak; tests `scope isolation` |
| Retrieval semantics | `recall`/`list` declare `input {scope, kind?, cursor?, limit?}`, `output {records, nextCursor, total}`, `ordering: createdAt asc + id tiebreak deterministic`, `limits: limit 1..32 default 32, MAX_PAGE 32`, `empty: [] with null cursor`, `invalid: {code, message}`, `failure: injected provider failure propagates {code: provider.error}` |
| Persistence boundary | Provider is injected; `InMemoryProvider` is default; `list` pagination is cursor-based (`cursor = lastId`); no filesystem or browser storage is imported; `memory.mjs` has zero `process.env`/`fs`/`path` reads beyond manifest self-reference |
| Bounded state | `MAX_STORE_BYTES 131072`, `MAX_RECORD_BYTES 65536`, `MAX_RECORDS 10000`, `MAX_PAGE 32` — enforced and tested |
| Sensitive-data guard | `content` containing `password`/`secret`/`apiKey`/`token` is rejected `ERR_SENSITIVE_CONTENT` (tested) |
| Relationship | `lifecycle: Memory survives Context replacement (Context->references Memory, not owns)` — explicit in `memory.json#relationship` and covered by `lifecycle` test |
