## §4 Implementation

Three new modules, one error family each (`*Error.code = 'lego.contract_violation'`
family + canonical provider/transport translation; errors contract 1.2.0 untouched):

- **`model-provider-adapter.mjs` (1081 lines, 11 exports)** — `createModelProviderAdapter`
  with injected `{exchange, authorize, recordUsage, now, newId}`; closed config shape
  (published provider-kind fields only; credential field names and secret-shaped values
  refused at the door); 6 gateway ops exactly as locked; `describeProviderConfiguration(null)`
  → `{configuration:'not-configured', reportedAs:'capability-unavailable', valid:true}`;
  state machine `not-configured|configured|available|unavailable|degraded|disabled`.
- **`tool-provider-adapter.mjs` (957 lines, 11 exports)** — same discipline for the tool
  dialect: 7 ops, provider-confirmed ∧ declared intersection for lists/describes,
  `tool.call` = one exchange with `sideEffects` + optional approval presence,
  `requestId` required, replay cache returns references only (no second exchange),
  same-requestId-different-payload → `request-id-reuse`, transport failure records
  nothing (honest explicit retry allowed).
- **`external-runtime.mjs` (476 lines, 6 exports)** — `createExternalRuntime` behind the
  P2.21 seam: synchronous `exchange` per seam contract, `declaration()` →
  `{contract:'ai.agent-runtime@1.0.0', executorKinds:['EXTERNAL'], …}`, `translate(op)`
  byte-identical to `RUNTIME_LIFECYCLE_TRANSLATION` (unsupported →
  `lego.contract_violation`, matching the seam), transport-kind → canonical error map,
  bounded `maxExchangeCalls 1024` → `lego.backpressure`, cancellation bookkeeping that
  never lies (undeclared capability → seam `missing-capability`, no executor cancel),
  no `console.*`, no `node:*` imports.

## §5 Adapter semantics (honesty + no fake provider)

`provider = none` exercises load/validate/list/policy/describe with zero adapters and no
crash; no default provider/model/auto-discover path exists (factories refuse missing
config with `lego.contract_violation`); disabled/degraded states refuse or mark honestly;
provider failures map through one canonical table (`unavailable|deadline_exceeded|
backpressure|access_denied|dependency_disabled|contract_violation…`) with **no body, key,
prompt or endpoint echo**; P2.24 usage statuses preserved — missing figures are
`{status:'unavailable', value:null}` and are **never recorded as 0**; reported figures
travel with `estimator:null`, no `estimated` claim is ever minted by an adapter;
retries with the same `requestId` never double-count (foundation record identities derived
deterministically from the call identity).

## §6 Security / privacy

Credentials are never stored/logged/rendereed: `FORBIDDEN_CONFIG_FIELDS`
(apiKey/token/credentials/authorization/headers/secret/password) refused by name with a
message that never echoes the value; full-form secret detector (`sk-`+24+, `ghp_`+36,
`github_pat_`, `Bearer …`, PEM header — P2.23 full-form lesson) applied to config values
and to error detail values (`[redacted]`, detail ≤64 chars); closed config shape refuses
unknown fields; authorization is a call-time handoff naming the published permission +
opaque grant reference (presence → `ai.approval` decides; config can never grant);
no `console.*`/`node:http|https|fs|crypto|child_process` in any adapter (static asserts);
R4 public-surface only (arch gate clean, zero new allowance); network authority lives
only at the injected exchange edge — AI Foundation remains a non-network executor.
