## Domain boundaries

- **Artifact — opaque reference only.** `storageRef` never dereferenced (no `readFile`/`writeFile`/
  `exec`/`spawn` call-form anywhere in the module — static test), traversal/absolute path-shaped
  refs refused, checksum = `sha256:<hex>` format fail-closed + deterministic
  `artifactContentDigest` (same content → same digest; no fake checksums), secret-shaped
  metadata/values refused, bounded registry (256).
- **Approval — fail-closed decision boundary.** Required scope; states `requested→granted|denied|
  expired`; decisions quoted `granted|denied|expired`; no implicit/auto/silent grant;
  `evaluate()` = DENY by default (unknown-approval, not-granted, expired, scope-mismatch,
  identity-mismatch all deny with stable reasons); unknown decision input REJECTED; expired
  resolve refused; duplicate request refused; same-decision replay idempotent, conflicting
  second decision refused; never an executor.
- **Audit — bounded structured records.** Fixed field set incl. canonical `correlationId`/
  `causationId`; event types quoted from canonical `events.types` + `artifact.referenced`;
  injectable clock + id factory (deterministic tests); capacity-bounded ring (default 512,
  drop-oldest deterministic); secret-shaped and reasoning-shaped keys/values refused
  (no chain-of-thought, prompts, completions, transcripts); no unbounded append anywhere.
