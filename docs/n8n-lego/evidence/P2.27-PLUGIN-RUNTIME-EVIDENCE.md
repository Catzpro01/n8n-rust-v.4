  optional field whitelist (unknown top-level fields reject), kebab ids,
  `major.minor.patch` via `compat.parseVersion`, canonical trust/locality
  classes only, capability bound 32 + pattern + no duplicates, dependency bound

  digest/signature/provenance/sbom shapes, **range grammar = `compat.mjs`
