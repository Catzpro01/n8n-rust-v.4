## P2.27.8 — Circuit breaker + deadline propagation + contract replay (slice record)

**Date:** 2026-09-24 · **Base:** main `f338418f`

### Landed

- `plugin-failure.mjs` — §16 + §17:
  - `createCircuitBreaker`: CLOSED/OPEN/HALF_OPEN, **lazy clock-driven
    transitions (no timers, no loops)**, threshold open, denial via published
    **`lego.unavailable`** (retryable + `retryAfterMs`), **single-flight**
    half-open probe (success → CLOSED with counters reset; failure → OPEN with
    fresh cooldown), knob bounds fail closed.
  - `withDeadline`: children derive through canonical
    `lego.envelope.deriveEnvelope` — the child≤parent clamp (§17) is the
    envelope's own rule, consumed not reimplemented; exhausted parent →
    published **`lego.deadline_exceeded`**, cancelled parent →
